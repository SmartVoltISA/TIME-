# Ω-TIME-011 — Временная структура как отношение изменений

## Статус
PASS — в пределах проверенной модели.

## Вопрос
Можно ли получить временную структуру без предварительного введения глобальной временной координаты?

## Гипотеза
Порядок событий может возникать из различимых изменений и причинных связей между состояниями.

## Минимальная конструкция
S₀ → S₁ → S₂ → …

Различимое изменение задаёт событие. Причинные связи задают частичный порядок событий.

## Результат
Глобальный clock не требуется для построения порядка. Однако порядок сам по себе не задаёт длительность и абсолютный масштаб.

## Контрпроверка
Одна и та же последовательность может быть параметризована с разной скоростью. Поэтому:

порядок ≠ метрическое время.

## Вывод
Временная структура может быть реляционной: она выражает порядок и отношения между изменениями. Это не доказывает фундаментальность или эмерджентность физического времени во Вселенной.

## Ограничение
Не выведены абсолютная единица времени и физическая метрика времени из минимального набора фундаментальных элементов.
