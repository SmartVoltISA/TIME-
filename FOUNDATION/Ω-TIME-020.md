# Ω-TIME-020 — Может ли причинная/лоренцева метрика возникнуть из структуры графа?

## Статус
OPEN / NEGATIVE CONTROL.

## Цель
Проверить, может ли структурный граф сам по себе породить не только положительно определённую метрику, но и лоренцеву причинную структуру без предварительного введения времени, сигнатуры `(−,+,+,+)` или скорости света `c`.

## Исходная модель
Пусть система задана неориентированным графом с неотрицательными весами `w_ij ≥ 0`.

Его лапласиан:

`L = D − W`.

Структурная квадратичная форма:

`ds² = dqᵀ L dq`.

Для любого `q`:

`qᵀLq = 1/2 Σ_ij w_ij (q_i − q_j)² ≥ 0`.

Следовательно, при этих предположениях форма является евклидовой/римановой (положительно полуопределённой), а не лоренцевой.

## Проверка 1 — спектральная сигнатура

Для случайного симметричного графа с `n = 12` и `w_ij ≥ 0` получены собственные значения лапласиана:

`≈ [0, 0, 0, 0, 0.2140, 0.5141, 0.8646, 1.1828, 1.9137, 2.6064, 2.6189, 3.5463]`.

Нулевая часть соответствует компонентам/нулевым модам графа; отрицательных физических собственных направлений нет.

**Результат:** PASS для отрицательного контроля: обычный положительный граф не генерирует лоренцеву сигнатуру.

## Проверка 2 — инвариантность при перепараметризации

Та же структурная длина `ds` не зависит от выбора параметра, которым вычислительно обходится траектория. Это согласуется с ранее проверенной идеей, что параметризация пути не должна сама создавать физическое время.

**Результат:** PASS для reparameterization invariance.

## Проверка 3 — причинный конус

Одной положительно определённой квадратичной формой условие вида

`g(v,v) < 0`

невозможно: отрицательных направлений нет.

Следовательно, из такого `L` нельзя получить разделение на timelike / null / spacelike направления и конечный причинный конус.

**Результат:** FAIL как попытка вывести причинную структуру из одного положительного графового лапласиана.

## Проверка 4 — попытка добавить знак

Если искусственно заменить форму на

`g = −α dt² + dqᵀL dq`,

то лоренцева сигнатура появляется. Но `dt`, отрицательный знак и коэффициент `α` уже внесены извне.

Это не вывод времени из структуры, а введение требуемой геометрии вручную.

**Результат:** FAIL как фундаментальная деривация; PASS только как контроль воспроизведения известной лоренцевой формы.

## Проверка 5 — конечная скорость распространения

Чистая графовая диффузия задаётся оператором первого порядка по внешнему времени и не создаёт сама по себе лоренцевого причинного конуса. Для гиперболической динамики требуется дополнительная структура второго порядка/инерции или эквивалентное ограничение распространения.

Если такая структура вводится заранее, наличие конечной скорости уже является частью модели, а не следствием одного графа.

**Результат:** OPEN. Требуется найти минимальный структурный инвариант, из которого одновременно следуют гиперболичность и причинность.

## Что зафиксировано

1. Положительный графовый лапласиан естественно даёт риманову/евклидову структурную форму.
2. Этого недостаточно для лоренцевой сигнатуры.
3. Лоренцева сигнатура требует дополнительного знакового или динамического инварианта.
4. Причинный конус не следует из одной положительной меры различий.
5. Поэтому нельзя пока утверждать, что пространство-время и его причинность уже выведены из Ω-фундамента.

## Новая граница поиска

Нужно искать не «время» непосредственно, а минимальную структуру, которая способна породить одновременно:

`difference → relation → dynamics → invariant measure + causal cone`.

Кандидаты для проверки:

- конкурирующие/противоположные связи;
- инерционный слой;
- ограничение скорости передачи изменения;
- знакопеременная или ориентированная связь;
- двухслойная структура состояния и изменения;
- причинный порядок как первичный объект, из которого метрика возникает позднее.

## Решение

Ω-TIME не закрыт.

На текущем уровне наиболее строгая рабочая формула остаётся:

`T[γ] = ∫_γ dμ`,

где `μ` — физически определённая инвариантная мера на допустимых состояниях/событиях.

Но происхождение `μ` и причинного конуса пока не выведено.

## Rule
FACT → CHECK → RESULT → DECISION → FIXATION.

FAIL здесь означает отрицательный результат конкретной попытки, а не провал всей гипотезы времени. История предыдущих PASS/OPEN не переписывается.
