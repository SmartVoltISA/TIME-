# Ω-TIME-021 — Причинный конус и ограничение распространения

## Статус
PASS для локального дискретного механизма распространения; OPEN для фундаментального вывода лоренцевой геометрии.

## Цель
Проверить, может ли причинная структура возникать из самой структуры связей, не вводя глобальное время как независимый параметр.

## FACT
В лоренцевых теориях причинная структура задаётся световыми конусами/метрикой. В подходах causal set причинный частичный порядок рассматривается как первичная структура, из которой пытаются восстановить геометрию. Это известный внешний контроль, а не результат Ω. См. Eichhorn (2019), Surya (2019). 

## MODEL A — положительно взвешенный граф
Для графа с положительными весами:

`L = D − W`

и

`Q(x) = xᵀ L x ≥ 0`.

Следовательно, обычный графовый лапласиан задаёт положительно полуопределённую, риманову структуру. Одного такого объекта недостаточно для сигнатуры `(-,+,+,+)`.

## RESULT A
FAIL как самостоятельный механизм получения лоренцевой сигнатуры.

Если добавить отрицательное направление вручную, например

`ds² = −dτ² + dx² + dy² + dz²`,

то лоренцева структура получается, но это уже предположение, а не вывод из графа.

## MODEL B — динамическая связь
Рассмотрена дискретная волновая динамика

`q̈ + Lq = 0`.

Для линейной цепочки локальное возмущение распространяется только на соседние вершины за один дискретный шаг. В вычислительном контроле при начальном возбуждении центральной вершины носитель расширялся:

`{10} → {9,11} → {8,10,12} → {7,9,11,13} → ...`

То есть локальность связей сама создаёт конечную скорость распространения относительно дискретного шага динамики.

## CONTRAST — диффузия
Для первого порядка

`q̇ = −Lq`

ненулевое влияние появляется на удалённых вершинах сразу (математически мгновенные хвосты). Следовательно, ограниченная скорость не следует просто из графа; она появляется из сочетания локальной связи и второго порядка динамики/инерционного состояния.

## RESULT B
PASS: локальная структура + инерционный второй порядок способны породить причинно ограниченное распространение без введения глобального физического времени в саму структуру связей.

Но дискретный шаг всё ещё является параметром модели. Поэтому это не доказательство фундаментального происхождения времени.

## КЛЮЧЕВОЕ РАЗДЕЛЕНИЕ
Получены три разных слоя:

1. **Порядок:** какие изменения могут следовать за какими.
2. **Причинное ограничение:** какие влияния могут достигать каких состояний.
3. **Мера:** насколько велик интервал вдоль допустимой траектории.

Нельзя автоматически отождествлять эти три слоя.

## ВАЖНЫЙ ВЫВОД
Для Ω недостаточно одного `L`. Нужна дополнительная структура, которая одновременно:

- выделяет допустимое направление причинного влияния;
- задаёт локальность;
- обеспечивает конечную скорость распространения;
- допускает инвариантную меру вдоль причинных траекторий;
- в пределе может дать эффективную лоренцеву сигнатуру.

Рабочий кандидат — не просто симметричный граф, а **ориентированная/подписанная динамическая связь** с различением распространяющей и восстанавливающей компонент.

## Что НЕ доказано
- что Ω выводит специальную теорию относительности;
- что полученная скорость обязана быть `c`;
- что лоренцева сигнатура возникает автоматически;
- что масса является исключительно инерцией графа;
- что `μ` из Ω совпадает с физическим proper time.

## DECISION
Не добавлять `−dt²` вручную.
Продолжить с минимальной структурой, способной породить причинный конус из локальных связей и динамики.

Следующий узел: **Ω-TIME-022 — знаковая/ориентированная связь, устойчивость причинного конуса и инвариантная скорость распространения.**
