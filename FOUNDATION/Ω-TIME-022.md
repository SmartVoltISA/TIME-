# Ω-TIME-022 — Минимальная знаковая связь, причинный конус и инвариантная скорость

## Статус
OPEN / PARTIAL PASS.

## Цель
Проверить, можно ли получить причинный конус и конечную скорость распространения не добавляя заранее метрику Минковского или готовое `-dt²`.

## FACT
Для гиперболических волновых уравнений конечная область влияния является стандартным свойством; аналогичные результаты существуют и для волновых уравнений на метрических графах. Это внешний контроль, а не результат Ω. [Kostrykin, Potthoff, Schrader, 2012]

## Ω-модель
Рассмотрены локальные связанные степени свободы `u_i` и сопряжённый поток `v_i` на цепочке/графе.

Ключевая структура:

`u_dot = B v`

`v_dot = c² Bᵀ u`

При локальном `B` получаем второй порядок:

`u_ddot = c² B Bᵀ u`.

Для пространственного оператора с соответствующим знаком это эквивалентно волновому типу:

`u_tt = c² Δ_G u`.

Относительный минус между временным и пространственным секторами появляется из закона динамического сопряжения, а не из положительно определённого графового расстояния.

## Численный контроль
На одномерной локальной решётке выполнены два сравнения:

1. волновая динамика второго порядка;
2. диффузионная динамика первого порядка.

Для волновой схемы область зависимости расширяется локально на один узел за шаг. На 1, 2, 5, 10 и 20 шагах граница зависимости находится соответственно на расстояниях 1, 2, 5, 10 и 20 узлов.

Для физически наблюдаемой амплитуды граница может быть менее резкой из-за дискретизации, но причинная зависимость самой схемы остаётся локальной.

Для диффузионной схемы аналогичная локальная численная зависимость не является доказательством физической конечной скорости: непрерывное уравнение теплопроводности имеет мгновенную ненулевую область влияния.

## Контроль знака
Если использовать только положительно определённый лапласиан `L`, квадратичная форма

`qᵀ L q >= 0`

не создаёт лоренцеву сигнатуру.

Если же динамическое сопряжение задаётся так, что временной сектор имеет противоположный знак относительно пространственного, получается гиперболический оператор. Это даёт причинный конус в модели.

Следовательно, минимальным кандидатом является не просто граф `G`, а ориентированная/двухсекторная структура с различием знаков между секторами.

## Что прошло
- локальность → локальная область зависимости: PASS;
- динамика второго порядка → волновой тип: PASS;
- противоположный знак секторов → гиперболический характер: PASS в модельном контроле;
- конечная скорость как отношение параметров динамики: PASS;
- возможность нормировать модель так, чтобы `c=1`: PASS.

## Что НЕ прошло
- вывод абсолютного значения `c` из одного графа: FAIL;
- вывод физической размерности времени: FAIL;
- вывод полного `(−,+,+,+)` пространства-времени из неориентированного положительного графа: FAIL;
- вывод специальной теории относительности из Ω: OPEN;
- вывод постоянства `c` для произвольной динамики: OPEN.

## Ключевой результат
Причинный конус может быть связан не с самим расстоянием между состояниями, а с **знаковой структурой закона изменения**.

Рабочая цепочка теперь:

`связь → локальность → сопряжённые сектора → знак → гиперболическая динамика → конечная скорость → причинный конус`

Это существенно отличается от гипотезы «граф сам является пространством-временем».

## Ограничение
Параметр `c` пока введён как коэффициент относительной скорости секторов. Его абсолютный масштаб не выведен. Поэтому утверждать фундаментальное происхождение скорости света нельзя.
