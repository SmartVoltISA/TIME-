# Ω-TIME-023 — Происхождение относительной скорости из жёсткости и инерции

## Статус
OPEN.

## Цель
Проверить, можно ли получить коэффициент скорости распространения как внутреннее отношение параметров структуры, а не задавать его отдельно.

## Модель
Для локальной цепочки рассматривается структурная динамика

`M q̈ + K q = 0`,

где `M` — инерционная матрица, а `K` — матрица связи/жёсткости.

Для длинноволнового режима дисперсия имеет вид

`ω² ≈ (K_eff/M_eff) k²`.

Следовательно,

`c² = K_eff / M_eff`.

## Проверка
При одновременном масштабировании

`K → aK`, `M → aM`

отношение `K/M` не меняется. Поэтому `c` является безразмерно-относительным структурным инвариантом после выбора единиц, хотя его физическая размерность требует внешнего масштаба длины/времени.

При изменении только `K` скорость меняется как `sqrt(K)`; при изменении только `M` — как `1/sqrt(M)`.

## Результат
PASS — относительная скорость может быть выражена через отношение жёсткости к инерции.

OPEN — абсолютная физическая величина скорости не выводится без размерностного масштаба.

## Значение для Ω
Это связывает предыдущие элементы:

`связь → жёсткость → инерция → отношение → скорость распространения`.

Тем самым `c` не обязательно является первичным объектом модели. Первичным может быть отношение двух структурных свойств.

## Ограничение
Это стандартный результат волновой динамики. Новизна для Ω возможна только если `K` и `M` сами будут независимо выведены из более глубоких инвариантов Ω. Сейчас это не доказано.

## Следующий тест
Проверить, могут ли `K` и `M` быть получены из одного и того же фундаментального набора различий/связей без независимого назначения.
