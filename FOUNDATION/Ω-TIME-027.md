# Ω-TIME-027 — Минимальный вариационный принцип без предварительного времени

## Status
OPEN / partial PASS / fundamental derivation FAIL.

## Question
Можно ли получить одновременно без заранее введённой координаты времени: (1) инвариантную меру траектории, (2) эффективную инерцию, (3) восстановительную структуру, (4) гиперболическую причинность и (5) нужную знаковую структуру?

## Candidate principle
Используем реляционную (Jacobi-type) функциональную форму

`S_J[γ] = ∫ sqrt(2(E-U(q))) ds_M`,

где `ds_M² = dqᵀ M(q) dq`.

Здесь параметр траектории не обязан быть физическим временем. Функционал инвариантен относительно монотонной перепараметризации одной и той же кривой.

## Check 1 — reparameterization
Для одной и той же геометрической траектории параметр `λ` был заменён на `σ=λ³`.

Численно для тестовой траектории получено:

`S_J(λ) = 7.695742281539764`

`S_J(σ) = 7.695740260527064`

Разность `≈2.02×10⁻⁶` при дискретном численном интегрировании; при уточнении сетки она уменьшается. Это соответствует ожидаемой инвариантности функционала относительно перепараметризации.

**Result: PASS (численный контроль).**

## Check 2 — восстановление параметра изменения
После выбора фиксированной энергии `E` из вариационного принципа можно восстановить параметр траектории через

`dτ = ds_M / sqrt(2(E-U))`.

Таким образом, параметр, играющий роль времени, может быть реконструирован из структуры траектории и ресурса, а не введён как независимый глобальный clock.

**Result: PASS как механизм реконструкции; это не доказательство фундаментальности.**

## Check 3 — общая инерция и восстановление
Если структурный оператор `L` задаёт метрику конфигурационного пространства, например

`M = m0 I + αL`,

а тот же структурный объект входит в `U(q)`, то после выбора параметра траектории возникают второпорядковые уравнения и модальная динамика.

Это подтверждает совместимость с Ω-TIME-026: общий relational operator может участвовать в кинематической и восстановительной частях.

**Result: PASS as a model.**

## Check 4 — hyperbolicity / causal cone
Здесь появляется принципиальная граница.

Положительная конфигурационная метрика `M` и обычный положительный потенциал `U` не порождают автоматически лоренцеву знаковую структуру. Вариационный принцип сам по себе не выбирает гиперболический principal symbol для пространственно-временной теории.

Чтобы получить конечный причинный конус, нужно дополнительно получить из более фундаментальной структуры гиперболический класс динамики: вещественные характеристики и конечную область влияния.

**Result: OPEN.**

## Negative control A — Euclidean positive structure
Если вся квадратичная форма остаётся положительно определённой, получаем положительную метрику. Это не даёт автоматически сигнатуру `(-,+,+,+)`.

**Result: FAIL as a derivation of Lorentzian signature.**

## Negative control B — arbitrary sign insertion
Если вручную заменить один знак на отрицательный и получить лоренцеву форму, это может дать нужную гиперболичность, но знак был внесён предположением.

**Result: FAIL as a fundamental derivation.**

## Negative control C — first-order diffusion
Переход к первому порядку `ẋ + Lx = 0` сохраняет релational coupling, но даёт диффузионное распространение, а не волну с конечной скоростью.

**Result: FAIL for causal-wave propagation.**

## Check 5 — relation to Ω-TIME-026
Для локальной цепи с

`M = m0 I + αL`,

`K = βL`,

численный спектр обобщённой задачи `K v = ω² M v` имеет низкочастотную ветвь `ω² ∝ q²`. Для теста `m0=1`, `α=0.7`, `β=1.3` линейная оценка дала

`c² ≈ 1.22758`.

Следовательно, конечная скорость может оставаться производной отношением структурных коэффициентов, но сами `M`, `K` и их знаки пока заданы моделью.

**Result: PASS as structural dynamics.**

## Main result
Вариационный принцип без предварительно заданного времени действительно позволяет сделать важный шаг: параметр времени может быть вторичным параметром реконструкции траектории, а не независимой фундаментальной сущностью.

Но один этот принцип НЕ выводит автоматически:

- лоренцеву сигнатуру;
- гиперболичность;
- универсальный причинный конус;
- физическую константу `c`;
- физический источник инвариантной меры `μ`.

## Decision
**PARTIAL PASS:** relational/reparameterization-invariant variational structure supports emergence/reconstruction of a temporal parameter and is compatible with shared inertia/restoring structure.

**FAIL:** the minimal positive variational structure does not by itself derive Lorentzian sign/hyperbolicity.

**OPEN:** fundamental source of the sign structure and the invariant measure remains unresolved.

## Boundary
Мы получили не «время из ничего», а более строгую конструкцию:

`relational structure → trajectory measure → reconstructed temporal parameter → dynamics`.

Для перехода к физическому пространству-времени требуется ещё один фундаментальный механизм, который выбирает гиперболический/лоренцев класс, а не положительно-евклидов класс.
