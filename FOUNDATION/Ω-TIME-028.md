# Ω-TIME-028 — Конкурирующие связи и происхождение гиперболического знака

## Status
OPEN / structural PASS / fundamental derivation OPEN.

## Question
Может ли гиперболический класс возникнуть из разности и конкуренции двух противоположных каналов без заранее вставленной лоренцевой метрики?

## Minimal model
Берём два канала `a` и `b` и только их реляционную разность

`d = a - b`.

Естественная квадратичная форма разности:

`Q_d = (a-b)^2`.

Её матрица

`D = [[1,-1],[-1,1]]`

имеет собственные значения `0, 2`.

Следовательно, чистая разность создаёт вырожденную положительную полуопределённую форму, но НЕ лоренцеву сигнатуру.

**Result: FAIL as direct derivation of Lorentzian signature.**

Это важный отрицательный контроль: сама идея «две противоположности → минус» недостаточна.

## Check 1 — symmetric competition dynamics
Рассмотрим минимальную динамику двух каналов

`u_dot = A u`,

где

`A = [[0,g],[g,0]]`.

Собственные значения:

`λ = ±g`.

При `g ≠ 0` спектр вещественный и имеет два противоположных направления распространения.

Для `g = 0` оба направления исчезают.

**Result: PASS for a minimal source of opposite real characteristic speeds.**

Но это пока свойство первого порядка, а не доказательство лоренцевой метрики.

## Negative control 1 — antisymmetric coupling
Для

`A = [[0,g],[-g,0]]`

собственные значения равны

`λ = ± i g`.

Характеристические скорости не являются вещественными.

**Result: FAIL for causal propagation.**

Следовательно, противоположность знаков связи сама по себе не достаточна: важна именно структура оператора, определяющая спектр главного символа.

## Check 2 — does difference itself create the minus sign?
Нет.

`(a-b)^2 = a² - 2ab + b²` действительно содержит отрицательный смешанный член, но квадратичная форма остаётся положительной полуопределённой. Наличие отрицательного cross-term нельзя отождествлять с отрицательной собственной метрикой.

**Result: FAIL.**

## Check 3 — what actually produces hyperbolicity?
Минимальная двухканальная система с симметричной противоположно направленной динамикой даёт спектр `(+g,-g)`. Это означает реальную характеристическую структуру.

Для пространственной системы вида

`∂_t u = A ∂_x u`

вещественные собственные значения `A` дают реальные характеристики `dx/dt = λ`.

Таким образом, гиперболичность может быть связана не с ручной вставкой метрики, а с существованием двух противоположных реальных характеристик.

Однако переход от такой кинематической структуры к фундаментальной квадратичной форме типа `(-,+)` всё ещё требует дополнительного вывода.

**Result: PARTIAL PASS.**

## Stability control
Для второго порядка

`M x_ddot + K x = 0`

требуется положительная определённость `M` и неотрицательность соответствующей восстановительной формы `K` для устойчивых осцилляторных мод.

Если отрицательный знак вставляется непосредственно в `M` без механизма ограничения, появляются отрицательные/неустойчивые степени свободы.

**Result: PASS as stability boundary; arbitrary sign insertion remains invalid as derivation.**

## Main result
Получено важное разделение:

`difference ≠ Lorentzian sign`

но

`opposed relational channels → real ± characteristic speeds`

может быть минимальным источником гиперболического класса.

То есть Ω получает первый кандидат на механизм причинного конуса, который не начинается с готовой метрики.

Но пока доказано только:

`competition/orientation structure → hyperbolic first-order characteristics`

а не

`Ω-foundation → physical Lorentzian spacetime`.

## Decision
**PASS:** минимальная симметричная конкурирующая связь даёт вещественный спектр `±g` и, следовательно, две противоположные характеристики.

**FAIL:** простая разность `(a-b)^2` сама по себе не порождает лоренцеву сигнатуру.

**FAIL:** кососимметричная связь даёт мнимый спектр и не является источником гиперболической причинности.

**OPEN:** ещё не выведено, почему именно двухканальная конкуренция должна приводить к фундаментальной лоренцевой квадратичной форме и универсальной скорости.

## Boundary
Мы не имеем права пока говорить «время/пространство возникли из битвы». Получено более узкое утверждение: определённый класс конкурирующей реляционной динамики способен порождать реальную двунаправленную характеристическую структуру без предварительного задания лоренцевой метрики.
