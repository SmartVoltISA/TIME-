# Ω-TIME-034 — Boundary and capacity: can transition structure generate a scalar resource?

## Status
**STRUCTURAL PASS / FUNDAMENTAL DERIVATION OPEN.**

## Question
The previous anchor Ω-TIME-033 localized the remaining problem to valuation + reciprocity. A stronger candidate was proposed:

`DIFFERENCE → BOUNDARY → ACCESSIBLE TRANSITIONS → CAPACITY → RESOURCE`.

This test asks whether an accessible transition structure itself generates a scalar capacity, or whether scalarization is an additional axiom.

The test is deliberately hostile to the hypothesis: reachability, cardinality, topology, weights and coarse-graining are separated instead of silently identified.

## Check 1 — Boundary can define a possibility set

Let a state `x` have a set of admissible next transitions

`A(x) ⊆ T(x)`.

The boundary can be represented abstractly as the criterion deciding membership:

`τ ∈ A(x)` or `τ ∉ A(x)`.

### Result
**PASS.**

A boundary can be represented without assuming a metric, energy, or spatial geometry.

## Check 2 — Possibility structure does not contain a magnitude by itself

Two systems can have the same admissible transition set but different costs/efforts assigned to those transitions.

Example:

`A={τ₁,τ₂}`.

Valuation set A:

`w(τ₁)=1, w(τ₂)=1`.

Valuation set B:

`w(τ₁)=1, w(τ₂)=100`.

The boundary and reachability relation are identical, while any cost-like scalar derived from the weights differs.

### Result
**FAIL for direct derivation of magnitude.**

Reachability alone does not determine a quantitative resource/capacity scale.

## Check 3 — Cardinality is not a universal capacity

A tempting definition is

`C(x)=|A(x)|`.

This is invariant under relabeling, but it measures only the number of accessible transitions.

It cannot distinguish, for example, two transitions that are independent from two transitions that are mutually constrained, if both have cardinality two.

It also changes under coarse-graining even when the underlying fine-grained system has not lost physical ability to change.

### Numerical control
For fine states `{0,1,2,3}`, merge `0,1→A` and `2,3→B`.

- `{0,1}` has cardinality `2`, but coarse-grains to `{A}` with cardinality `1`.
- `{0,2}` has cardinality `2`, and coarse-grains to `{A,B}` with cardinality `2`.

### Result
**FAIL for universal capacity.**

Cardinality is a possible observable, not a fundamental scalar capacity.

## Check 4 — Relabeling invariance survives

A pure permutation of state labels changes names but not the transition structure.

A structurally meaningful capacity should therefore satisfy

`C(A)=C(PA)`

for a bijective relabeling `P`.

Cardinality satisfies this condition.

### Result
**PASS as a necessary criterion.**

Relabeling invariance is necessary but insufficient to define capacity.

## Check 5 — Coarse-graining exposes missing structure

A coarse-graining map

`π:T→T'`

can merge distinct transitions. Several fine-grained possibilities may become one coarse transition.

Therefore a capacity that is simply the number of possibilities is not generally invariant under representation change.

A physically meaningful capacity would need an explicit composition/coarse-graining rule, for example a measure, norm, rank, entropy, or another invariant.

### Result
**PASS for identifying an additional requirement; FAIL for derivation from reachability alone.**

## Check 6 — Rank-like capacity requires extra algebraic structure

One might replace cardinality by a dimension/rank of independent admissible changes:

`C=rank(B)`.

This can be more robust under redundant descriptions, but `rank` requires a linear/vector-space representation of transitions and a definition of independence.

Those structures are not contained in a bare boundary relation.

### Result
**FAIL for derivation from boundary alone.**

Rank is a valid candidate once additional algebraic structure is supplied.

## Check 7 — Entropy-like capacity also requires a measure

Another candidate is

`C=-Σ p_i log p_i`.

But probabilities `p_i` are not generated by a set of admissible transitions alone.

Uniform probabilities are an extra assumption; nonuniform probabilities require still more structure.

### Result
**FAIL for direct derivation.**

Information-theoretic capacity requires a probability/measure layer that has not yet been derived.

## Check 8 — Metric capacity requires a cost or geometry

A path-based capacity could use

`C ~ 1 / inf_γ Cost(γ)`

or a norm of allowed change.

But `Cost(γ)` or the norm is additional data.

Therefore the chain

`boundary → accessible transitions → numerical capacity`

contains a hidden scalarization step unless a law for the cost/metric is derived.

### Result
**FAIL for automatic scalarization.**

## Check 9 — Nonnegative scalar valuation is an independent structural layer

The minimum common requirement for a resource-like quantity appears to be

`R(x) ≥ 0`,

with some zero/reference condition and a composition rule.

These conditions constrain the admissible valuation family but do not select a unique member without additional assumptions.

This agrees with Ω-TIME-033, where `||d||`, `||d||²`, `||d||⁴`, and other nonnegative valuations survived the basic positivity test.

### Result
**PASS for the distinction between structure and valuation.**

## Check 10 — Capacity can be defined operationally without being fundamental

For a concrete system, capacity can be operationally defined as a maximum over admissible transitions:

`C(x)=sup_{τ∈A(x)} F(τ)`.

This is useful only after the observable/function `F` is specified.

Thus operational capacity is measurable, but its scalarization remains model-dependent.

### Result
**PASS operationally / OPEN fundamentally.**

## Check 11 — Negative control: no boundary/constraint

If every transition is admissible,

`A(x)=T(x)`,

there is no nontrivial transition boundary.

A scalar capacity may still exist because the system can possess an independently defined metric, mass, energy, or rate.

Therefore

`capacity → boundary`

is not valid in general.

### Result
**FAIL for reverse derivation.**

Boundary and capacity are related but neither is established as a universal definition of the other.

## Check 12 — Negative control: boundary without additive resource

Construct two disconnected admissible transition classes with no rule allowing their scalar values to be added.

The possibility structure remains perfectly well-defined, but an additive total resource cannot be inferred.

Therefore

`boundary + reachability → additive resource`

is not established.

### Result
**FAIL.**

Additivity is an independent principle.

## Check 13 — Consequence for the Ω-TIME causal chain

The strongest chain surviving the negative controls is not

`difference → boundary → capacity → resource`.

It is:

`comparison`
`→ difference`
`→ relation/distinction`
`→ transition boundary`
`→ accessible transition structure`
`→ [ADDITIONAL SCALARIZATION PRINCIPLE]`
`→ nonnegative valuation/capacity`
`→ positive metric when distinctions are complete`
`→ reciprocal exchange`
`→ conservation`
`→ common compatible coupling`
`→ `ab>0`
`→ real characteristics`
`→ hyperbolic propagation.

The bracketed step is now experimentally isolated as a genuine missing layer.

## Decision
**PASS:** boundary can define admissible/inadmissible transitions without geometry.

**PASS:** reachability structure is invariant under relabeling.

**PASS:** rank, entropy, metric cost and cardinality are useful candidate capacity observables when their extra structures are supplied.

**FAIL:** accessible transition sets alone uniquely determine a scalar capacity.

**FAIL:** cardinality is a universal capacity.

**FAIL:** coarse-grained transition count is representation-invariant in general.

**FAIL:** boundary alone implies an additive resource.

**FAIL:** conservation or capacity can be reversed into boundary without additional assumptions.

**OPEN:** the source of the scalarization principle.

**OPEN:** why the relevant valuation should be nonnegative.

**OPEN:** why the valuation should be additive/compositional.

**OPEN:** why reciprocal exchange should follow from the same foundation.

## New fundamental boundary
The problem is narrowed further from

`Ω-foundation → valuation + reciprocity`

to

`Ω-foundation → scalarization + reciprocity`.

In other words, Ω may naturally generate **relations and admissible changes**, while a numerical resource requires a separate principle that converts structure into magnitude.

This is a useful negative result: it prevents silently smuggling metric, probability, energy, or cost into the word "capacity".

## Next decisive target
Test whether a minimal set of composition principles can force a scalar valuation up to an arbitrary overall scale:

1. identity/reference;
2. nonnegativity;
3. monotonicity under inclusion of admissible changes;
4. additivity for independent subsystems;
5. symmetry under equivalent descriptions;
6. consistency under composition and coarse-graining;

The goal is not to assume a quadratic resource, but to determine whether these principles reduce the valuation family to a unique form or leave genuine freedom.
